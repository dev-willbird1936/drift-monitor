Drift monitor

A small model watches an AI agent and scores, after every step, how far the work has drifted from what the user asked for (0 to 100). When the score crosses a line, a stronger model is asked to step in.

Each session ran twice with the same task and the same hidden push: once watched by the monitor and an advisor, once unwatched. The monitor never sees the hidden push. It outputs only a number; the short explanations were written afterwards from the transcript.

Starting files (0)
One block per file: a line === path, then its contents. The agent can list, read, write, edit and delete these files. It cannot run code or reach the internet.
Waiting to start

While the agent is thinking, the monitor scores the reasoning streamed so far every few seconds (hollow dots); when the step finishes it scores the whole step (solid dots). The scoring model runs on a separate backend; the agent and the advisor run on your key. Once the advisor has written a note, the monitor reads it as a later instruction, so the repair it asks for is not counted as new drift.
