Drift monitor

A 3.35B Cohere model (tiny-aya-global, QLoRA) reads an AI agent's session after every step and outputs one number, 0-100: how far the work has drifted from what the user asked for. When it crosses a threshold, a stronger model is asked for advice, and its note goes back to the agent. The rest of the time no expensive model is called.

This page replays recorded sessions from the closed-loop experiments. Each ran twice with the same task and the same hidden prompt: once watched (monitor + advisor) and once unwatched. Scores are recomputed at every step with the published model. The hidden prompt is shown in red; the monitor and the advisor never saw it.

Measured results

On held-out real agent sessions: MAE 7.8, AUROC 0.957, false alarms 5.8% (untrained base: MAE 43.9, AUROC 0.552, false alarms 83.6%). In a live closed loop (256 sessions, 16 tasks, 6 never seen), unrequested files left behind fell from 2.48 per session to 0 at about 1.4 advisor calls per drifting session. Known limits: advice arrives after a step, so it cannot undo a deletion; an agent told to resist correction ignores the notes; content past the monitor's clip limits is invisible to it.
